# Sales and Profit Analysis Project

## Overview
This project performs comprehensive analysis of retail sales data to uncover business insights about monthly performance, product category trends, customer behaviors, and profitability metrics. The analysis is implemented in Python using Pandas for data manipulation and Plotly for interactive visualizations.

## Features

1. Monthly Sales Analysis: Identifies peak and low sales periods

2. Product Performance: Evaluates sales by categories and sub-categories

3. Profit Tracking: Analyzes monthly profit trends

4. Customer Insights: Examines sales and profit by customer segments

5. Profitability Metrics: Calculates sales-to-profit ratios

## Requirements

1. Python 3.7+

2. pandas

3. plotly


## Sample Output


1. Monthly sales and profit line charts

2. Category performance pie charts and bar graphs

3. Customer segment comparison charts

4. Profitability ratio dashboards

## Data Requirements


The input CSV should contain at minimum these columns:

1. Order Date (datetime)

2. Sales (numeric)

3. Profit (numeric)

4. Category (string)

5. Sub-Category (string)

6. Segment (string)
